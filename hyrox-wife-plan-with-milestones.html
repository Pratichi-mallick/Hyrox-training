Hyrox Doubles reference — stations and split rules
StationOpen Doubles standardHow you split it

Eight 1 km runs, each followed by one station. Both partners run every kilometre; station work is shared. Practise the handover itself — transitions are where doubles pairs lose the most time.

1:30 allocates 57:10 to the eight kilometres — an average of 7:09/km on legs coming off a station — with 30:10 of shared station work and 2:40 of transitions. That is anchored to Louise\u2019s current 7:00/km flat 10K, because in doubles both partners run every kilometre, so the pair\u2019s run pace is set by the slower runner, not the faster one.
